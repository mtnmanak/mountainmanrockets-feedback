# Mountain Man Rockets — site feedback

This is the public bug and feature-request tracker for
[mountainmanrockets.com](https://www.mountainmanrockets.com).

## Found a problem with the site?

- **Have a GitHub account?** [Open an issue](../../issues/new). A sentence or two is
  plenty — what page you were on, what you expected, what happened instead. A screenshot
  helps if it's a visual problem.
- **No GitHub account?** Email
  [admin@mountainmanrockets.com](mailto:admin@mountainmanrockets.com) and I'll file it
  here myself. You don't need an account to *read* anything on this page.

## What belongs here

- Site bugs — broken links, layout problems, something wrong on a phone, a download that
  doesn't work
- Feature requests — things the site could do or content you'd like to see covered

## What belongs elsewhere

- **Questions and discussion about a page's content** — use the comments on that page
- **Anything else** — the [contact page](https://www.mountainmanrockets.com/contact/)

The [open issues](../../issues) list is the real queue — it's what I work from, so
anything filed here is logged, visible, and not forgotten.
